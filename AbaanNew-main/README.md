# AbaanNew

A modern, high-performance React application built with [Vite](https://vitejs.dev/). This project is designed for speed, scalability, and maintainability, leveraging the latest web tooling, best practices, and custom component architecture.

> 🚀 Built and maintained by [Shivam Gupta](https://github.com/ShivamIT23)

---

## ✨ Features

- ⚡️ Lightning-fast bundling with **Vite**
- ⚛️ Component-based UI using **React 18**
- 🔄 Hot Module Replacement (HMR) for seamless development
- 🧼 Code quality enforced via **ESLint**
- 🎨 Scalable and responsive design
- 📁 Modular folder structure
- 🛠️ Easy to extend and maintain

---

## 🔧 Tech Stack

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [ESLint](https://eslint.org/)
- [Tailwind CSS](https://tailwindcss.com/) *(if used)*
- [Framer Motion](https://www.framer.com/motion/) *(if used)*
- [SimpleBar / Lenis / GSAP](https://github.com/idiotWu/smooth-scrollbar) *(if applicable)*

## 📦 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ShivamIT23/AbaanNew.git
cd AbaanNew
```

---

### 2. Install dependencies

```bash
npm install
```

---

### 3. Start development server

```bash
npm run dev
```

> The app will run locally at http://localhost:5173
